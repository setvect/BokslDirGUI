# 03. 탐색 조직화: 탭, 히스토리, 북마크, 경로, 검색, 사이드바

## FR-11. 탭

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-11.1 | 좌/우 패널은 각각 탭을 가질 수 있어야 함 | Must |
| FR-11.2 | 새 탭은 현재 패널 상태를 복제해 생성하고 활성화 | Should |
| FR-11.3 | 탭 닫기를 지원하되 마지막 탭은 닫지 않아야 함 | Must |
| FR-11.4 | 탭 목록 보기와 특정 탭 전환 지원 | Must |
| FR-11.5 | 탭 제목은 현재 경로의 마지막 이름 또는 루트 경로로 표시 | Should |
| FR-11.6 | 패널별 최대 탭 수 정책 제공; 기존 구현 기준은 패널당 5개 | Should |
| FR-11.7 | GUI 탭바에서 클릭 전환, 닫기 버튼, 드래그 재정렬 지원 가능 | Should |
| FR-11.8 | 재시작 시 열린 탭·활성 탭·활성 패널·정렬·숨김 표시·필터·탐색 히스토리 복원 | Must |
| FR-11.9 | 삭제·연결 해제된 저장 경로의 홈 대체와 안내, 압축 암호·파일 선택 저장 금지 | Must |

**수용 기준**

- 창의 일반 크기와 최대화 상태 저장·복원, 기존 설정 파일의 선택 필드 미포함 허용
- 직접 경로 입력·북마크·탭 전환·일반 탐색의 공통 세션 저장
- 좌측 탭과 우측 탭은 서로 독립적으로 전환
- 탭이 2개 이상일 때 패널 제목 영역에 탭 개수 또는 탭바가 표시
- 탭 목록에서 화살표·Page Up/Down으로 이동하고 Enter로 탭 선택
- 탭 목록에서 개별 탭 버튼·Delete로 닫기 가능, 마지막 탭의 닫기 비활성화

## FR-12. 디렉토리 히스토리

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-12.1 | 패널별 방문 디렉토리 히스토리 저장 | Must |
| FR-12.2 | 뒤로/앞으로 이동 지원 | Must |
| FR-12.3 | 히스토리 목록 보기와 목록에서 이동 지원 | Must |
| FR-12.4 | 히스토리 전체 삭제 또는 현재 경로만 남기기 기능 제공 | Should |
| FR-12.5 | 히스토리는 재시작 후 복원 | Should |
| FR-12.6 | 히스토리 개수 제한을 두어 설정 파일이 무한히 커지지 않게 해야 함; 기존 구현 기준은 패널당 100개 | Should |
| FR-12.7 | 뒤로/앞으로 버튼의 길게 누르기 또는 드롭다운으로 히스토리 목록 표시 가능 | Should |

**수용 기준**

- 뒤로/앞으로 버튼과 단축키가 같은 히스토리 스택 사용
- 존재하지 않는 과거 경로는 복원 시 무시하거나 오류 없이 건너뛰기
- 탭 목록과 같은 경로 행·폭, 현재 항목 초기 포커스, 화살표·Page Up/Down·Enter로 이동·선택

## FR-13. 북마크

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-13.1 | 현재 디렉토리를 북마크로 추가 기능 제공 | Must |
| FR-13.2 | 북마크 목록을 표시하고 선택한 경로로 이동 기능 제공 | Must |
| FR-13.3 | 북마크 이름 변경과 삭제 지원 | Must |
| FR-13.4 | 같은 경로의 중복 북마크 추가를 방지 | Should |
| FR-13.5 | 중복 이름은 자동으로 고유 이름을 제안 | Should |
| FR-13.6 | 북마크는 설정 파일에 저장되어 재시작 후 복원 | Must |
| FR-13.7 | GUI에서는 사이드바/즐겨찾기 영역 제공 가능 | Should |
| FR-13.8 | 북마크는 드래그 정렬, 그룹/폴더 분류를 후속으로 지원 가능 | Could |

**수용 기준**

- 북마크 추가 후 목록에 즉시 표시
- 삭제/이름 변경 후 설정 저장이 수행
- 목록의 삭제 버튼·Delete/Backspace로 지정 항목 삭제, 현재 경로 유지, 마지막 항목 삭제 후 닫기 버튼 포커스, 저장 실패 시 항목 복원
- 사용자 지정 이름과 경로의 분리 표시, 전체 경로 툴팁, 탭 목록과 같은 화살표·Page Up/Down·Enter 이동·선택

## FR-25. 사이드바와 빠른 위치

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-25.1 | 사이드바는 홈, 데스크톱, 문서, 다운로드 등 표준 위치 표시 | Should |
| FR-25.2 | 사이드바는 드라이브/볼륨/마운트 포인트 표시 | Should |
| FR-25.3 | 사이드바는 북마크와 최근 폴더 표시 | Should |
| FR-25.4 | 사이드바 항목 클릭 시 활성 패널의 경로가 이동 | Must if implemented |
| FR-25.5 | 사이드바 항목을 반대 패널로 열기 또는 새 탭으로 열기 옵션 제공 가능 | Could |
| FR-25.6 | 사이드바는 접기/펼치기와 폭 조절 지원 | Should |

**수용 기준**

- 사이드바 위치 클릭이 현재 활성 패널에 반영
- 존재하지 않는 위치는 비활성 표시하거나 목록에서 제거

## FR-26. 주소창과 Breadcrumb

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-26.1 | 패널별 breadcrumb 경로 표시 제공 | Must |
| FR-26.2 | breadcrumb 조각 클릭으로 해당 상위 경로로 이동 | Must |
| FR-26.3 | 주소창 직접 입력 제공 | Must |
| FR-26.4 | 주소창은 `~`, 상대 경로, 절대 경로, 공백/한글 경로 처리 | Must |
| FR-26.5 | 주소창은 자동완성 후보와 히스토리 제안 제공 | Should |
| FR-26.6 | breadcrumb 조각 우클릭/드롭다운으로 하위 폴더 빠른 이동 제공 가능 | Should |

**수용 기준**

- breadcrumb와 주소창은 같은 패널 경로 상태 공유
- 입력한 경로가 유효하지 않으면 현재 경로를 유지하고 오류 표시
