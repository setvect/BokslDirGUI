## macOS·Windows 다음으로 열기

- 파일 컨텍스트 메뉴와 파일 메뉴의 `다음으로 열기…` 제공
- OS가 제공하는 연결 앱 목록에서 기본 앱 표시 및 앱 이름 검색 지원
- OS 등록 앱 식별자로 선택 실행, 실행 전 목록 재조회와 임의 실행 파일 거부 필수
- 실행 파일 경로가 없는 Windows 등록 앱의 선택 허용, 표시용 경로와 실행 식별자 구분
- 선택 앱 버튼 클릭 또는 방향키·Enter로 대상 파일 열기
- 기본 파일 연결과 기존 Enter·더블클릭의 기본 앱 열기 유지
- 대상 파일 경로 표시와 취소·조회 재시도·실행 오류 안내 제공

## 현재 폴더의 파일 관리자·터미널 열기

- macOS Finder·Terminal과 Windows 파일 관리자·터미널을 동일 공통 액션으로 제공
- Windows 기본 터미널은 시스템 Windows PowerShell, 미설치 시 Windows Terminal 별칭 사용
- 두 터미널 모두 미설치 시 실행 오류 안내, 현재 폴더·PATH의 임의 실행 파일 대체 금지
- 현재 패널의 실제 디렉터리만 전달, 한글·공백·따옴표·셸 특수 문자의 문자 그대로 처리 필수
- 메뉴·컨텍스트 메뉴·도움말은 백엔드 기능 지원 정보와 동일한 노출 기준 유지

## Finder 파일 클립보드 연동

- macOS 파일 선택의 `Cmd+C`를 시스템 파일 URL 클립보드에 기록, Finder와 양방향 붙여넣기 지원
- `Cmd+V`의 공통 복사 작업, `Option+Cmd+V`의 확인 후 이동 작업 연결
- 붙여넣기 실행 시 클립보드·원본 존재·요청 대상 재검증, 다른 폴더로 이동한 뒤 도착한 응답 무시
