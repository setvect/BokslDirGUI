# 요구사항 개요

## 1. 근거와 해석 원칙

### 1.1 근거 우선순위

1. 실제 구현 코드 `BokslDir/src/**`
2. 저장소 운영 가이드 `BokslDir/AGENTS.md`
3. 제품 문서 `BokslDir/docs/PRD.md`, `BokslDir/docs/Requirements.md`, `BokslDir/docs/User-Manual.md`
4. README

- 기존 저장소는 문서 간 상태가 어긋날 수 있으므로 실제 코드를 우선하라고 명시
- 따라서 이 요구사항 세트는 다음 구분

- **기존 구현 기반 요구사항**: 코드와 사용자 문서에서 확인되는 동작
- **GUI 전환 추가 요구사항**: 데스크톱 GUI가 되면서 자연스럽게 추가 가능한 상호작용/화면/OS 연동
- **후속 검토 요구사항**: 기존 문서에는 있으나 코드 근거가 약하거나 기준 기능 이후 검토가 적절한 기능

### 1.2 GUI 전환 해석

- 기존 TUI의 정체성인 **키보드 중심 듀얼 패널 파일 매니저** 유지
- GUI에서는 마우스, 컨텍스트 메뉴, 드래그 앤 드롭, 사이드바, 미리보기, 작업 큐를 1급 기능으로 추가
- 기존 터미널 제약(최소 80x24, raw mode, IME 경고)은 GUI에서 작은 창 대응, 한글 입력 안정성, 네이티브 입력 처리 요구사항으로 재해석
- 기존 Rust 로직 재사용은 요구사항 범위 밖
- 단, 기존 기능과 UX 의도는 제품 기준으로 사용

## 2. 제품 목표

### PRD-1. 듀얼 패널 중심의 고속 파일 관리

- 신규 GUI 앱은 좌/우 두 패널을 동시에 보여주며, 활성 패널 기준으로 파일 탐색·선택·작업 수행 필수

**수용 기준**

- 앱 실행 시 기본 화면은 좌/우 듀얼 패널 구조 제공
- 사용자는 활성 패널을 명확히 구분 가능
- 복사/이동은 “활성 패널 → 반대 패널” 흐름을 기본값으로 제안
- 단일 패널 보기 또는 좁은 창 대응 모드 제공

### PRD-2. 키보드 숙련자와 GUI 일반 사용자를 모두 지원

- 기존 BokslDir의 Vim/F키 기반 속도감을 유지하되, GUI에서는 메뉴·툴바·마우스 조작으로도 모든 주요 기능에 접근 가능해야 함

**수용 기준**

- 주요 기능은 메뉴/버튼/컨텍스트 메뉴/단축키 중 최소 2개 이상의 접근 경로 보유
- 기존 핵심 단축키는 가능한 한 호환 또는 사용자 설정 가능한 형태로 제공
- 단축키 도움말/검색 UI 제공

### PRD-3. 파일 작업의 안전성과 복구 가능성 우선

- 삭제·이동·덮어쓰기·압축 해제 같은 위험 작업은 명시적인 확인, 충돌 처리, 진행률, 취소, 오류 요약 제공 필수

**수용 기준**

- 모든 장시간 파일 작업은 UI를 블로킹하지 않음
- 작업 진행률은 파일 수, 바이트 수, 현재 항목, 속도, 예상 남은 시간 표시
- 사용자는 작업 중 취소 가능
- 충돌 발생 시 덮어쓰기/건너뛰기/모두 덮어쓰기/모두 건너뛰기/취소 선택 가능
- 작업 완료 후 양쪽 패널이 최신 상태로 갱신

## 3. 우선순위 맵

### 3.1 기존 TUI 기능 동등성 기준

- 듀얼 패널 탐색
- 파일 목록 표시/메타데이터/타입 아이콘
- 키보드·마우스 기본 탐색
- 더블클릭, 우클릭 컨텍스트 메뉴
- Shift/Cmd/Ctrl 클릭 다중 선택
- 복사/이동/삭제/휴지통/영구삭제
- 새 폴더/이름 변경/속성 보기
- 정렬/필터/숨김 파일
- 진행률/충돌/취소/오류 요약
- Breadcrumb + 주소창
- 테마 4종과 한국어/영어 UI
- 북마크/히스토리/경로 직접 이동
- OS 기본 앱 열기

### 3.2 2차 기능

- 패널별 탭
- 패널 간/폴더 간 드래그 앤 드롭
- 사이드바
- 작업 큐/진행률 패널
- 미리보기 패널/빠른 보기
- 압축 생성/해제/미리보기/암호
- 드라이브/마운트 포인트 고급 UI
- 외부 에디터/터미널 명령 실행
- 패널 비율 조정/단일 패널 모드

### 3.3 후속 검토 기능

- 파일 내용 검색/grep UI
- 검색 결과 가상 패널
- 단축키 커스터마이징
- 파일 연결 프로그램 설정 관리
- 자주 쓰는 외부 프로그램 북마크
- 최근 파일/폴더 이력 별도 화면
- 일괄 이름 변경의 정규식·접미사 확장
- 폴더 비교/동기화
- 디스크 사용량 분석
- 파일 비교
- 커스텀 테마 편집기
- 명령 팔레트
