# 05. 커스터마이징, 플랫폼, 품질: 테마, i18n, 설정, 보안, 성능

## FR-19. 테마와 표시 설정

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-19.1 | Dark, Light, High Contrast, Mdir 테마 제공 | Must |
| FR-19.2 | 런타임 테마 전환 지원 | Must |
| FR-19.3 | 선택한 테마는 재시작 후 복원 | Must |
| FR-19.4 | 커스텀 테마 파일 또는 GUI 테마 편집은 후속 기능으로 검토 | Could |
| FR-19.5 | 파일 크기 표시는 자동 단위와 바이트 표시 전환 기능 제공 | Should |
| FR-19.6 | 아이콘 표시 방식은 호환성 문제를 고려해 전환 가능 | Should |
| FR-19.7 | 고대비 모드는 접근성 요구사항으로 취급 | Must |
| FR-19.8 | 보기 모드, 미리보기 패널 표시 여부, 사이드바 표시 여부 저장 기능 제공 | Should |

**수용 기준**

- 테마 전환 즉시 전체 UI에 적용
- 앱 재시작 후 마지막 테마가 유지
- Mdir 테마: 검정 파일 목록·청록 메뉴/테두리·회색 경로/상태 줄·붉은 디렉터리·노란 선택 표시 적용
- 메뉴 포커스: 밝은 청록 배경·검정 글자/단축키·짙은 청록 상단 외곽선 적용, 포커스된 비활성 항목은 짙은 회색 글자로 구분
- 색상 참고: [경향신문의 Mdir III 3.10 화면](https://www.khan.co.kr/article/201904201016001), 화면 색상 참고 후 현대 GUI의 대화상자·오류·비활성 상태에 맞게 명도 조정
- 추가 참고: 사용자 첨부 캡처 2개와 Google 이미지 검색의 [Mdir 3.10 화면](https://virtualwindows.tistory.com/5)·[디렉터리 목록 화면](https://hongjstf.tistory.com/616) 비교
- 포커스: 파일 종류별 기본 글자색을 행 배경으로 사용·검정 글자로 반전, 선택된 포커스 행의 왼쪽 표식도 검정으로 반전
- 필터 일치: 포커스 행에서는 반전 색을 유지하고 밑줄로 일치 구간 표시
- 분류 우선순위: 실제 링크·디렉터리·압축 종류 우선, 배치/셸 스크립트 구분 후 실행 권한·확장자 분류 적용
- 범위: Mdir 색상만 적용, 다른 테마·실제 파일 종류·열기/실행·키보드 조작·파일 작업 동작 유지

| 표시 분류 | Mdir 기본 글자색 | 대표 확장자/조건 |
| --- | --- | --- |
| 디렉터리 | 빨강 | 실제 디렉터리·상위 폴더 |
| 문서 | 청록 | txt, md, pdf, doc/docx, hwp/hwpx, xls/xlsx, csv, ppt/pptx |
| 실행 파일 | 초록 | 실제 실행 파일, exe, com, msi, msix, appimage |
| 배치·셸 스크립트 | 노랑 | bat, cmd, ps1, sh, bash, zsh |
| 심볼릭 링크 | 하늘색 | 실제 링크 종류 우선·대상 확장자 무시 |
| 이미지 | 분홍 | png, jpg/jpeg, gif, webp, svg, ico, heic, avif |
| 압축·디스크 이미지 | 주황 | zip, 7z, rar, tar.gz, bz2, xz, iso, dmg |
| 오디오·동영상 | 연보라 | mp3, wav, flac, mp4, mkv, mov, webm |
| 소스 코드 | 흰색 | c/cpp, rs, py, js/ts, jsx/tsx, html, css, sql |
| 기타 | 회색 | 미분류·확장자 없음 |

- 현대 확장자 분류: Mdir 캡처의 문서/실행/배치 구분을 기준으로 추가, 원본의 모든 확장자별 설정을 복제한 것으로 간주 금지
- 확장자 대소문자 구분 없음, 마지막 확장자 기준·다중 확장자 압축 파일의 최종 압축 확장자 인식

## FR-20. 언어와 한글/Unicode

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-20.1 | 한국어와 영어 UI 지원 | Must |
| FR-20.2 | 런타임 언어 전환 지원 | Must |
| FR-20.3 | 선택 언어는 재시작 후 복원 | Must |
| FR-20.4 | 사용자 노출 문자열은 렌더링 코드에 하드코딩하지 않고 i18n 키를 통해 관리 | Must |
| FR-20.5 | 한글 파일명, CJK 문자, 이모지, 결합 문자를 포함한 파일명이 깨지지 않게 표시 | Must |
| FR-20.6 | 모든 입력창은 UTF-8 문자 단위 커서 이동/삭제를 정확히 처리 | Must |
| FR-20.7 | GUI에서는 기존 터미널 IME 경고 대신 네이티브 입력기 동작을 자연스럽게 지원 | Must |
| FR-20.8 | 정렬/검색/필터는 Unicode 대소문자와 조합 문자 처리를 고려 | Should |

**수용 기준**

- 한글 파일명을 가진 항목이 잘림/선택/정렬/이름 변경 과정에서 깨지지 않음
- 한국어 UI로 전환하면 메뉴, 다이얼로그, 상태바, 도움말이 함께 변경

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-21.1 | 테마, 언어, 히스토리, 북마크 저장 | Must |
| FR-21.2 | 설정 파일은 앱 전용 설정 경로에 저장 | Must |
| FR-21.3 | 설정 스키마 버전을 두고 호환되지 않는 설정은 안전하게 무시 | Should |
| FR-21.4 | 설정 저장 실패가 앱 사용을 막지 않아야 함 | Should |
| FR-21.5 | GUI에서는 설정 화면을 제공해 테마/언어/편집기/단축키 등 변경 기능 제공 | Should |
| FR-21.6 | 창 크기, 패널 비율, 사이드바/미리보기 표시 여부 저장 기능 제공 | Should |
| FR-21.7 | 설정 저장은 원자적 쓰기를 고려 | Should |

**수용 기준**

- 앱 종료 시 상태 저장을 시도하고, 다음 실행 시 복원
- 설정 파일이 손상되어도 앱은 기본값으로 시작

## FR-22. 알림, 토스트, 다이얼로그

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-22.1 | 정보/오류/확인/선택/입력/진행률 다이얼로그 제공 | Must |

| FR-22.5 | 다이얼로그는 키보드와 마우스로 모두 조작 가능 | Must |

- 다이얼로그에서 `Esc`는 취소/닫기로 동작
- 암호 입력 필드는 화면에 원문을 표시하지 않음

## FR-23. 보안과 데이터 보호

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| FR-23.1 | 파일 작업은 사용자가 명시적으로 선택한 경로와 항목에 대해서만 수행 | Must |
| FR-23.2 | 압축 해제는 대상 디렉토리 밖으로 파일이 쓰이지 않도록 경로를 정규화/검증 | Must |

| FR-23.6 | GUI 프레임워크가 웹뷰 기반일 경우 파일 시스템 API는 최소 권한으로 노출 | Must |
| FR-23.7 | 드래그 앤 드롭으로 들어온 외부 경로도 일반 파일 작업과 같은 검증을 거쳐야 함 | Must if implemented |
| FR-23.8 | 미리보기는 실행 가능한 콘텐츠를 자동 실행하지 않아야 함 | Must if implemented |

## NFR-2. 안정성

| ID | 요구사항 |
| --- | --- |
| NFR-2.1 | 모든 I/O 오류는 앱 크래시가 아닌 사용자 메시지로 처리 필수 |

| NFR-2.5 | 테스트 가능한 파일 작업 계층을 두어 실제 파일 시스템 회귀를 줄여야 함 |
| NFR-2.6 | 작업 큐가 있으면 앱 종료 시 진행 중 작업 처리 정책 명확화 필요 |
