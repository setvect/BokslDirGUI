# 06. 검증 기준과 근거

## 1. 기능 테스트 시나리오

1. 홈 디렉토리에서 앱을 실행하고 좌/우 패널이 모두 렌더링되는지 확인한다.
2. 좌측 패널에서 하위 폴더 진입 후 우측 패널 상태가 유지되는지 확인한다.
3. 더블클릭으로 폴더 진입과 파일 기본 앱 열기가 동작하는지 확인한다.
4. 우클릭 컨텍스트 메뉴에서 복사/이동/삭제/속성/경로 복사를 실행한다.
5. Shift 클릭, Cmd/Ctrl 클릭으로 다중 선택을 만들고 단축키 파일 작업을 실행한다.
6. 여러 파일을 선택하고 반대 패널로 복사한다.
7. 동일 파일명 충돌에서 “건너뛰기”와 “모두 덮어쓰기”가 각각 동작하는지 확인한다.
8. 큰 파일 복사 중 진행률과 취소가 동작하는지 확인한다.
9. 휴지통 삭제와 영구 삭제가 서로 다른 확인 흐름을 사용하는지 확인한다.
10. 한글 파일명 파일을 생성/이름 변경/필터링/삭제한다.
11. `*.md` 필터와 이름 정렬/크기 정렬을 확인한다.
12. Breadcrumb와 주소창으로 경로를 이동한다.
13. 북마크 추가 후 재시작하여 복원 여부를 확인한다.
14. 패널 간 드래그 앤 드롭 복사/이동을 확인한다.
15. 외부 Finder/Explorer에서 앱으로 파일을 드롭한다.
16. 미리보기 패널에서 이미지/텍스트/압축 파일이 안전하게 표시되는지 확인한다.
17. zip 압축 생성, 미리보기, 해제를 확인한다.
18. 한국어/영어 전환과 테마 전환 후 재시작 복원을 확인한다.
19. OS 기본 앱 열기와 Finder/Explorer에서 보기가 플랫폼별로 동작하는지 확인한다.
20. 작업 큐가 있을 경우 여러 작업의 순차 실행, 취소, 완료 알림을 확인한다.

## 2. 회귀 테스트 우선순위

- 파일 작업: 복사/이동/삭제/충돌/취소
- 마우스 이벤트: 더블클릭, 우클릭, Shift/Cmd/Ctrl 클릭, 드래그 앤 드롭
- 경로 처리: 상대/절대/홈/공백/한글/특수문자
- 압축 해제 보안: `../` 경로 차단
- 설정 복원: 정상/손상/구버전 설정 파일
- 대량 디렉토리: 렌더링/스크롤/정렬/필터
- 미리보기: 큰 파일, 깨진 파일, 지원하지 않는 파일
- 플랫폼 연동: 휴지통, reveal, 기본 앱 열기, 드라이브/마운트 포인트

## 5. 미확정/주의 사항

- 기존 문서에는 파일 내용 검색, 일괄 이름 변경, 단축키 커스터마이징, 파일 연결 설정, 디스크 사용량, 파일 비교가 포함되어 있으나, 현재 코드 근거가 강하지 않아 후속 검토 기능으로 분리했다.
- 기존 구현의 OS 기본 앱 열기는 macOS 우선이므로 GUI 요구사항에서는 Windows/Linux까지 확장해야 한다.
- 기존 TUI의 터미널 에디터/명령 실행은 GUI 보안·UX 측면에서 그대로 옮기기보다 외부 앱 열기/터미널에서 열기/명령 실행 옵션으로 재설계해야 한다.
- 드래그 앤 드롭과 파일 미리보기는 GUI 프레임워크별 OS 연동 차이가 크므로 기술 선택 단계에서 별도 검토가 필요하다.
- 작업 큐와 Undo는 데이터 안전성에 직접 영향을 주므로 구현 전 상세 설계와 회귀 테스트가 필요하다.
- 언어와 프레임워크 선택은 이 문서 범위가 아니며, 이 요구사항을 만족하기 쉬운 플랫폼 API, 파일 시스템 권한 모델, 패키징/업데이트 전략을 별도로 평가해야 한다.
