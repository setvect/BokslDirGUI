- 목적: UI 문제를 단계별로 발견하고, 수정 결과와 검증 증거를 같은 문서에서 추적한다.

## 1. 사용 방법

각 단계는 다음 순서로 진행한다.

1. 해당 단계의 검사 대상을 준비한다.
2. 체크리스트를 실제 Tauri 창에서 확인한다.
3. 발견한 문제를 이 문서의 결함 기록표에 추가한다.
4. 데이터 안전성과 작업 대상 오류를 먼저 수정한다.
5. 관련 자동 테스트를 추가하거나 강화한다.
6. 실제 Tauri 창에서 수정 결과를 다시 확인한다.
7. 완료 조건과 증거가 모두 충족된 경우에만 단계 상태를 완료로 변경한다.

체크박스 의미:

- `[ ]`: 미검사 또는 미완료
- `[x]`: 증거를 남기고 완료
- `[!]`: 결함 발견, 수정 필요
- `[-]`: 적용 대상 아님. 적용되지 않는 이유를 기록해야 함

단계 완료 시 다음 증거를 남긴다.

- 검사 날짜와 검사자
- 실행 환경과 OS
- 관련 action ID 또는 화면
- 재현 절차
- 수정한 파일
- 실행한 테스트와 결과
- 실제 창 확인 결과
- 스크린샷 또는 영상 경로
- 남은 위험

| 실제 destination 보유 | copy, move, archiveCreate, archiveExtract | 압축 생성은 활성 패널의 현재 디렉터리, 나머지는 반대 패널 또는 계산된 대상 디렉터리를 `대상 위치`로 표시 | 의미는 맞지만 설명·overview 중복은 UI-002 |

| working directory 보유 | createDir, shellCommand | 활성 패널 경로를 `현재 위치`로 표시 | 의미 적합 |

### 7.5 테스트 공백

- `OperationDialogHost.test.tsx`는 휴지통 대상 경로가 한 번 이상 표시되는지만 확인해 중복 횟수를 제한하지 않는다.
- `shortcutLabelForAction` 테스트는 `file.copy`가 `y`만 반환하는 현재 동작을 고정하고 있어 F5 누락을 문제로 잡지 못한다.

- navigation list 테스트는 `active tab`, `back`, `bookmark` 같은 group 문자열의 현지화를 검증하지 않는다.
- 기본 화면 테스트는 panel footer와 bottom status의 역할 중복을 판정하지 않는다.

### 8.2 수정 내용

#### UI-001·UI-002 — 작업 다이얼로그 중복과 라벨 의미

- 작업 설명은 제목 아래 한 번만 표시한다.
- source 목록은 별도 파일명 열 없이 식별 가능한 전체 경로를 항목당 한 번 표시한다.
- copy, move, archive create/extract만 `대상 위치`를 표시한다.
- create directory와 shell command만 `현재 위치`를 표시한다.
- trash, permanent delete, rename, properties, external action에서는 source 파일 경로를 `현재 위치`로 잘못 표시하지 않는다.
- source가 없는 current-folder 작업에서 빈 `대상 항목` 영역을 제거했다.
- 영구 삭제의 비가역 경고는 일반 설명과 분리해 한 번만 강조한다.

#### UI-007 — 충돌 비교 정보

- 원본과 대상을 별도 영역으로 구분했다.
- 각 영역에 전체 경로, 크기, 수정일을 표시한다.
- 좁은 화면에서는 두 열을 한 열로 전환한다.
- 기존 안전 기본값 `skip`, 위험 동작 강조, 전체 적용 선택지는 유지한다.

#### 상태 머신 문서 정합성

구현은 작업 접수 직후 `queued` 상태를 만들고 있었지만 설계 문서는 UI에서 생성하지 않는 예약 상태라고 설명했다. 실제 동작에 맞춰 `queued`를 backend 접수 또는 I/O 시작 대기 상태로 수정했으며, 단일 활성 작업 정책과 다중 큐가 아니라는 점을 유지했다.

### 8.3 회귀 테스트 보강

- 휴지통 다이얼로그에서 source 경로가 정확히 1회 표시되고 `현재 위치`가 나오지 않는지 검사한다.
- 다중 source의 각 경로와 destination이 각각 1회 표시되는지 검사한다.
- current-folder 작업에서 빈 source 영역이 나오지 않는지 검사한다.
- 충돌 원본·대상의 경로, 크기, 수정일을 비교할 수 있는지 검사한다.
- 혼합 다중 선택에서 가상 `..`를 제외하고 concrete entry만 listing 순서대로 전달하는지 검사한다.
