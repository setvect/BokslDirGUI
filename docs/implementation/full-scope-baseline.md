# 전체 구현 범위 기준선

## 1. 목적

첫 구현 목표를 축소 범위가 아니라 **기존 TUI BokslDir 기능 동등성 + GUI 전환 필수 기능**으로 고정한다.

## 2. 범위 분류

| 분류 | 정의 | 완료 시점 |
| --- | --- | --- |
| 기준 기능 | 기존 TUI 또는 요구사항 Must에 해당하는 기능 | 첫 기능 동등성 릴리스 전 완료 |
| GUI 전환 필수 | GUI 앱이 되며 동등성을 만족하기 위해 필요한 상호작용 | 기준 기능과 함께 완료 |
| 검증 게이트 기능 | 범위에는 포함되나 provider/OS/fixture 통과가 필요한 기능 | 게이트 통과 전 완료 표시 금지 |
| 후속 검토 | 기존 구현 근거가 약하거나 별도 UX/안전 설계가 필요한 기능 | 별도 ADR/PoC 후 착수 |

## 3. 기준 기능 목록

### 3.1 탐색/패널

- 좌/우 듀얼 패널, 활성 패널, 반대 패널 대상 작업.
- 패널별 현재 경로, 탭, 히스토리, 정렬, 필터, 선택, 스크롤 독립 유지.
- 상위/하위 이동, 뒤로/앞으로, refresh, compact breadcrumb/address edit.
- 홈/드라이브/마운트 quick access.

### 3.2 파일 목록/선택

- 파일/디렉토리/링크/실행 파일 타입 구분.
- 이름/크기/수정일/확장자/권한 등 metadata 표시.
- 디렉토리 우선 정렬, 숨김 파일 toggle.
- 단일/다중/범위/전체/반전/해제 선택.

### 3.3 파일 작업

- 복사, 이동, 삭제, 휴지통, 영구 삭제.
- 새 폴더, 이름 변경, 속성 보기.
- 충돌 처리: `overwrite`, `skip`, `allOverwrite`, `allSkip`, `cancel`.
- 진행률: 현재 항목, 파일 수, 바이트, 속도, ETA.
- 취소와 오류 요약.

### 3.4 압축/외부 연동

- zip, tar, tar.gz/tgz, tar.zst/tzst, jar, war, 7z 감지/목록/해제/생성.
- 7z/암호는 `archive-7z` 검증 게이트 통과 전 완료로 보지 않는다.
- OS 기본 앱 열기, 시스템 파일 관리자에서 보기, 외부 에디터 열기.
- 현재 경로에서 shell/terminal command 실행은 기존 TUI 동등성 범위에 포함하되, GUI에서는 기본 비활성 또는 명시 확인 정책으로 보호한다.

### 3.5 설정/도움말/i18n

- Dark/Light/High Contrast.
- 한국어/영어 런타임 전환과 저장/복원.
- 북마크/히스토리 저장/복원.
- action registry 기반 도움말.

## 4. GUI 전환 필수 기능

- 메뉴바, 컨텍스트 메뉴, compact toolbar/action affordance.
- 마우스 단일 클릭, 더블클릭, 우클릭, Shift/Cmd/Ctrl click.
- Drag and drop intent UI와 drop validation.
- 다이얼로그/토스트/시스템 알림 후보.
- 보조 패널은 기본 화면을 침범하지 않는 overlay/collapsed 방식.

## 5. 후속 검토 기능

- 파일 내용 검색/grep, 검색 결과 가상 패널.
- 일괄 이름 변경, 폴더 비교/동기화, 디스크 사용량 분석, 파일 비교.
- 커스텀 테마 편집기, 명령 팔레트, 외부 프로그램 북마크.

## 6. 범위 불변 조건

- 기존 TUI 기능을 제거하거나 후속으로 미루려면 별도 사용자 승인과 문서 변경이 필요하다.
- renderer는 광범위 파일 시스템 API를 직접 갖지 않는다.
- 모든 destructive operation은 확인/취소/오류 요약을 가져야 한다.
- 기준 기능 완료 전에는 “완료”를 선언하지 않는다.
